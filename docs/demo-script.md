# Three-minute Mess2Meal demo script

Record the actual running application after completing local setup. Do not present the dashboard concept illustration as a screenshot.

| Time | Show | Suggested narration |
|---|---|---|
| 0:00–0:20 | Dashboard overview | Mess2Meal is a prototype for coordinating surplus-food listings and recipient suggestions. |
| 0:20–0:55 | Add surplus food | Show the form and explain quantity, preparation time, best-before time, storage description and pickup location. Use clearly labelled test data. |
| 0:55–1:25 | Register recipient | Show preferences, capacity, urgency, availability and coordinator-entered distance. |
| 1:25–2:00 | Find matches | Select a listing, run matching and explain score reasons. Clarify that a match is not safety approval or confirmed acceptance. |
| 2:00–2:30 | Status and history | Demonstrate allowed transitions using a test listing and show the audit history. |
| 2:30–2:50 | Impact and CSV | Show delivered-only impact and identify CSV rows as synthetic demonstration data. |
| 2:50–3:00 | Limitations | State that live field validation, recipient verification and physical handover remain outside the prototype. |

Before publishing, check that no real phone numbers, private addresses or personal data are visible.
